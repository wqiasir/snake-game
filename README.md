# 🐍 贪吃蛇游戏

一个用原生 HTML / CSS / JavaScript 实现的经典贪吃蛇小游戏，**零依赖**，单文件即可运行——直接用浏览器打开 `snake.html` 即可游玩。

## 功能特性

- **操作方式**：方向键 / WASD 控制移动，空格键暂停/继续，`R` 或回车键重新开始
- **计分系统**：每吃一个食物 +10 分，最高分自动保存在浏览器 `localStorage`，刷新不丢失
- **难度递增**：吃得越多速度越快（自动提速），上限受保护
- **移动端适配**：支持触屏滑动控制方向
- **完整规则**：撞墙、撞到自己身体即结束；填满全屏判定通关。

## 如何运行

直接用浏览器打开 `snake.html` 即可，无需安装任何东西。

## 玩法截图提示

界面采用深色渐变主题，蛇身带渐变与眼睛（随方向转向），食物有呼吸脉冲动画，重开按钮醒目可点。
